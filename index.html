Features

该有的都有，不该有的不加

从安装到联机，功能都落在同一套原生后端里，界面保持中性、扁平、克制。

游戏与加载器

原版、Fabric、Quilt、Forge、NeoForge 与 OptiFine 一条安装流程，自动补齐原版文件。

  • 正式版 / 快照 / 愚人节 / 远古版本
  • OptiFine 独立安装或放入实例 mods
  • Mojang 官方与 BMCLAPI 镜像切换

下载引擎

对齐 PCL 的分段与换源策略：8MB 起步分段、单文件最多 12 条连接、全局 64 条连接。

  • 慢段自动对半拆分，已下载部分不重复
  • 慢源 8 秒识别并切换，慢主机缓存 5 分钟
  • Range 不支持时自动降级为单连接

内容管理

Modrinth 与 CurseForge 的搜索、详情、版本、安装，界面与网页版保持一致。

  • 模组 / 资源包 / 光影 / 数据包 / 世界
  • 前置依赖弹窗，可选依赖默认不勾选
  • 已安装按模组身份识别，版本不同也算
  • MC百科中文资料一键查看

联机

EasyTier 与陶瓦联机（Terracotta）并列，可按需切换。

  • 公共服务器延迟检测，支持自定义节点
  • 邀请码创建 / 加入房间
  • 陶瓦联机与 HMCL 房间码互通
  • 房间成员、房主虚拟 IP、局域网扫描

实例与整合包

每个实例独立 instance.json，导入已有版本时直接引用原目录，不复制存档。

  • 复制 / 导入 / 删除 / 重命名
  • 导出按 PCL 流程生成 mrpack 或 zip
  • 已识别文件写入清单，不重复打包
  • 支持整个 .minecraft 压缩的整合包
  • 实验室 · 离线生物群系地图（支持 26.x）

账户与启动

微软 OAuth 设备代码登录、LittleSkin 等第三方验证与离线账户，按 UUID 各自独立。

  • Java 自动扫描与按版本选择
  • classpath 合并、natives 解压、参数替换
  • 崩溃分析：Java 不兼容、类加载错误
  • 控制台实时日志与游戏时长统计

FAQ

常见问题

为什么打开后界面还是旧版本？

界面资源打包在 exe 内，并按哈希解压到 .aurora/app。如果看到旧界面，通常是仍在运行旧 exe。请先关闭所有同目录的启动器进程，再打开新版本。

提示缺少 .NET 或 WebView2 怎么办？

安装 .NET 6 Desktop Runtime（x64）即可；WebView2 在 Windows 10/11 一般已预装，缺失时可从微软官网安装 Evergreen Runtime。

离线 / 局域网联机为什么看不到皮肤？

离线与局域网不经过 Mojang 皮肤服务，需要在双方实例安装皮肤补丁（如 CustomSkinLoader）并自行配置；联机页的 EasyTier 与陶瓦联机只负责网络互通。

能导入 PCL / HMCL 的实例吗？

可以。启动时会扫描游戏目录下的 versions 并自动登记尚未导入的版本，也可手动导入整合包（.mrpack、zip 或整个 .minecraft 压缩包）。

陶瓦联机需要额外安装吗？

首次使用会在联机页自动下载并解压 Terracotta，进度显示在控制台卡片中。它与 HMCL 使用同一套房间码，两边创建的房间可以互相加入。
